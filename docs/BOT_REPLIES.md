# Каталог відповідей @toadbot

Реальні тексти бота. Це джерело для патернів у `parsing/families/` і golden-фікстур у `tests/fixtures/replies/`.

Позначення: `[e]` — кастомне емодзі (entity `MessageEntityCustomEmoji`). У тексті на його місці стоїть звичайний емодзі-замінник, тому **парсимо за ключовими фразами, а не за емодзі**. `[фото]` — повідомлення з медіа, текст у підписі (caption).

## Загальні спостереження

- Команди надсилаються як `@toadbot <Команда>`. Кнопки зі стрілкою ↗ — switch-inline: вони лише вставляють цей текст у поле вводу. Мітка кнопки може відрізнятися від команди: «С работы» → `@toadbot Завершить работу`, «Покормить» у «Моя семья» → `@toadbot Покормить жабенка`.
- Працюють і slash-аліаси: `/toad_info@toadbot` = «Жаба инфо».
- Бот відповідає **не реплаєм** і **не згадує власника** («Твоя жаба…», «Ваш жабёнок…»).
- Команди й відповіді видаляються приблизно через 5 хв.
- Час бота — UTC+3.
- Тривалість: `через 5 ч:34 мин.`, `через 2 ч:0 мин.`: години й хвилини завжди разом, через `ч:`.

## info — «Жаба инфо» (`/toad_info@toadbot`)

Спостережено 15:31, жаба на роботі (робота вже закінчилась, але не завершена).

```
[e]: Завершай работу
[e]: Покормить можно через 5 ч:34 мин.
(Откормить можно через 3 ч:34 мин.)

[e]: Недоступно во время работы
[e]: Можно на арену

[e]: Можно потусить
[e]: Ваба Жаша и Скала Json
[e]: Доступна подготовка к ограблению

[e]: Жаба в начальной точке
```

Кнопки (switch-inline): `С работы`, `На арену`, `Моя жаба`.

| Рядок | Поле | Відомі значення |
|---|---|---|
| 1 | робота | `Завершай работу` (готова до завершення). **[зібрати]** інші стани |
| 2 | кормежка | `Покормить можно через {h} ч:{m} мин.` **[зібрати]** стан «можна» |
| 3 | откорм | `(Откормить можно через {h} ч:{m} мин.)` |
| 4 | підземелля | `Недоступно во время работы` |
| 5 | арена | `Можно на арену` |
| 6 | туса | `Можно потусить` |
| 7 | брак | імена пари |
| 8 | ограблення | `Доступна подготовка к ограблению` |
| 9 | похід (карта) | `Жаба в начальной точке` |

Парсимо за фразами, а не за номерами рядків: порядок і кількість рядків можуть змінюватися залежно від стану.

## work.send — «Поход в столовую»

```
[фото]
Жабуля ушла работать в столовую! [e]

Работа - не walk:
[e] Единиц настроения: -20

[e] Жаба закончит работу через 2 ч:0 мин.
[e] Завершить работу можно будет с помощью команды «Завершить работу»
```

- Сімейство: `work.send`, `OK`.
- Дані: `mood_delta = -20`, `finish_in = 2 ч:0 мин.` → `finish_ready_at = message.date + 2h`.
- Тип роботи пишемо одразу, без попереднього «Отправить жабу на работу».

## work.finish — «Завершить работу»

```
Твоя жаба бежала с работы домой, а по дороге нашла несколько букашек!

Ты получил:
[e] Букашки: +76 ([e] +6 | [e] +6)
```

- Сімейство: `work.finish`, `OK`.
- Дані: `bugs = +76`; у дужках бонуси (стрекозюля, жучок) — інформативно.
- Спостереження: завершення о 15:31 → нова відправка о 15:32 прийнята. Отже 8-годинний цикл рахується від **відправки**, а не від завершення.

## family — «Моя семья»

```
[фото]
[e] Скала Json и Ваба Жаша:
[e] Дней в браке: 839
[e] Конфетки: 45

Ачивки:
[e] День влюблённых I
[e] В первый класс II

Ваш жабёныш:
[e] Имя: Бебилка
[e] Уровень: 16
[e] Сытость: 17/26
[e] Авторитет: 60/100
[e] Настроение: Спокойное
```

Кнопки (switch-inline): `Покормить` → `Покормить жабенка`, `Сделать подарок`.

Дані для `ChildState`: `name`, `level`, `satiety/satiety_max`, `authority/authority_max`, `mood`; для брака — `days_married`, `candies`.

## child.feed — «Покормить жабенка»

Відмова:

```
Ваш жабёнок отказался есть!

Итоги:
[e] Букашки: -75
```

- Сімейство: `child.feed`, `REFUSED` (букашки списано, результату немає).
- **[зібрати]** успішну кормежку і «ще рано».

## Ще потрібні зразки

- «Покормить жабу»: успіх; «ще рано».
- «Жаба инфо» в інших станах: жаба вільна, на роботі (ще не закінчила), кормежка доступна, жаба побита.
- Відправка на роботу, коли 8 год ще не минуло; «Завершить работу» до закінчення 2 год.
- Садок: відправка, «рано забирати», забирання, махач, відправка поза 06:00–12:00.
- «Покормить жабенка»: успіх; «ще рано».
- «Брак вознаграждение»: успіх; «ще рано» (формат із днями?).
- Загальні: «недостаточно букашек», «жаба нуждается в реанимации».
